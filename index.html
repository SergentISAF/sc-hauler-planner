How to get an API key (3 minutes)
  1. Go to console.anthropic.com and sign up (email, Google or GitHub).
  2. Verify your email when the confirmation lands.
  3. Click Billing in the left sidebar and add a payment method.
  4. Top up your account with $5–10 in credits (that's roughly 500–1000 parses).
  5. Go to API Keys in the sidebar and click Create Key. Give it a name like "hauler".
  6. Copy the key (starts with sk-ant-) — you can only see it once, so save it somewhere.
  7. Paste it in the field above. The key is stored only in your browser's localStorage and is sent directly to Anthropic, never to me.

⚠️ Don't share your key publicly. If you ever paste it on a shared/public machine, revoke it from the console afterwards.
